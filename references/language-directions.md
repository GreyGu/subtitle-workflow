# 语言方向与中文电影寻找英语字幕

## 统一角色，不固定某一种语言

`source_languages` 是实际原音轨语言，可多项；`target_language` 是这一份交付字幕的语言；`reference` 是核对依据，不天然等于英文稿。语言标签用于记录，例如 `zh`、`cmn`（普通话）、`yue`（粤语）、`en`、`en-GB`、`en-US`、`ru`、`zh-Hans`（简体中文）。平台搜索代码须按当时的接口/页面核实，不能把标签原样当成所有网站的参数。

| 相同流程角色 | 英语电影 → 中文/俄语 | 中文电影 → 英语 |
| --- | --- | --- |
| 语义基准 | 实际英语音轨及核对后的原文参考 | 实际普通话/粤语等音轨及核对后的原文参考 |
| 搜索对象 | 同版中文/俄语全文字幕 | 同版英语全文字幕，不只是外语台词/标牌字幕 |
| 主要语言风险 | 英语歧义、中文称谓、俄语性数格/敬称 | 省略主语、亲属称谓、时态、敬语、文化意象、方言 |
| 全片检查 | 结构 → 语义对应 → 时间轴 → 信达雅 | 同样步骤；不是先把中文转英语后就算验收 |
| 交付名称 | `movie.zh-Hans.srt` / `movie.ru.srt` | `movie.en.srt` 或按约定 `movie.en-GB.srt` |

扩展到法译俄、日译中或多语电影时只替换源/目标角色及语言习惯；不强制经由英语转译。必要的中间稿只能辅助，必须记录并返回原文确认。

## 中译英完整流程示例

以下是任务方法示例，不声称已经为某部真实影片找到或下载字幕。

1. **输入**：中文片名、年份、国际发行名、完整片源名、视频路径、实际音轨及版本、目标英语习惯、保存目录。用户未选英式/美式时记录“未指定”，使用一致、易懂的表达，避免自行添加地区俚语。港片不能仅因中文片名就假定普通话。
2. **搜索和下载**：组合原片名/国际片名＋年份＋`English subtitles`/`英语字幕`，再加实际发布名、发行版本或影片编号。优先检查本地内嵌英语轨和同版发行字幕，再比较可正常取得的候选。确认语言、是否完整翻译、是否来自配音稿、是否机器翻译及作者。保存原始包和页面/日期/指纹；下载失败不编造取得结果。
3. **原文基准**：使用匹配音轨的中文字幕/可靠转写；检查它是否删节、把方言改写，或来自另一配音版本。对白参考与同步参考可不同，但分别说明来源及关系；先建立与实际视频的联系再用来对时。
4. **结构和覆盖**：严格解码，扫描整份英语字幕；与源语对白逐句对应。标明旁白、背景话语、重叠对白、歌曲、关键书信/标牌、音效及无法转写部分。只覆盖外语台词的 `forced` 局部字幕不能冒充整片英语字幕。
5. **信达雅**：按三维逐句复核英语稿。源语省略的主语/单复数/时态只能依语境补足；“哥/姐/师傅/老师”先判断真实关系和功能，不机械译成亲属或职业。成语不照字面硬译，文化背景不替换成英美情境；文学语言、朴素对白、粗口、敬语各有合适语体。
6. **时间与可读性**：全片检查固定偏移、越播越不同步、删减断点；拆合句要复核内部顺序。英语变长时优先自然精炼和合理分行，不删核心含义。每行长度/每秒字符阈值按目标要求设置，播放验证不能只看数字。
7. **不足与修复**：没有合适全文稿时报告候选的局限；用户授权补译/制作才建立新稿。不能用无法听清的方言、配音改词或中间语言猜补。保留未解决时段。
8. **交付**：另存目标语言文件，验证备份后按授权替换；从最终目录重新读取并用独立工具核验。交付原始来源、修改清单、逐句对应、信达雅状态及实际声画检查范围。不要把模型文字复核称为英语母语者听校。

## 目标语言专项提示

- **英语**：统一拼写地区、标点和缩写；注意冠词、时态、单复数、代词回指及口语节奏。不为补齐英语语法而臆断原文故意隐藏的身份，可重组句子保留未知信息。
- **中文**：区分文字体系与音轨语言；简繁转换不等于校译。称谓、代词和成语须合语境，避免无依据的网络化/古文化。
- **俄语**：检查性数格、动词体/时态、`ты/вы` 与称谓、姓名译法；不能从无性别的中/英文孤句猜说话人性别。
- **其他语言与混合文字**：查该语言的真实规范和显示效果。现有脚本按 Unicode 码位粗计字符，不能等同所有语言的字形数/视觉宽度；阿拉伯文方向、组合字符、泰文断词、日文混排等应实际渲染核查。
